# Crux v0.12.0

Crux v0.12.0 fixes 18 verified bugs, hardens self-update, and tests on three platforms.

## Highlights

- `scip_map`, `scip_refs`, and `scip_callers` no longer report references of a same-name library symbol. A project `find` is separate from `str.find`.
- `scip_find` with `unreferenced=true` no longer hides dead code that shares a name with a library symbol.
- `scip_dead` with the default `exports_only=true` returns entries for Rust, Python, Go, Java, Kotlin, Scala, C++, and Dart. Before, only TypeScript and JavaScript returned entries.
- Lines such as `return helper` count as references again. Before, the import heuristic dropped them.
- The unreferenced sweep on a 2,300-symbol index takes 0.4 s instead of 5.2 s. Output is identical.
- A page that starts past the end of a result set returns a clear message with the `offset=0` hint.
- The server negotiates the MCP protocol version, answers JSON-RPC batch arrays, and writes each ledger line in one call.
- `crux <subcommand> --help` prints the usage of that subcommand.
- `crux setup` writes config files atomically, detects every spelling of an existing Codex registration, refreshes a stale binary path, and finds `claude.cmd` on Windows.
- `crux self-update` verifies the SHA-256 of the download against the `SHA256SUMS` release asset and replaces the real binary behind a symlink.

## Upgrade

```sh
crux self-update
crux setup codex
# Use `crux setup claude` for Claude Code.
```

Run setup again to refresh the persistent guidance. Restart the client and any persistent MCP process after the upgrade.

## Behavior changes

- Per-sub-project index files now end with a short digest, for example `index-rust-services__api-8aa9d413.scip`. The next `scip_index` run removes the old files.
- `scip_index` in auto-detect mode removes the index of a language it no longer detects and reports the removed files. Pass `language` or `languages` to keep such an index.
- `self-update` refuses a release that has no `SHA256SUMS` asset. Releases before v0.12.0 have none.
- The HTTP client is ureq 3. It ignores proxy environment variables, the same as before.
- The crate declares `rust-version = "1.85"`. Release binaries use fat LTO and strip symbols.

## Validation

CI runs fmt, clippy, and the test suite on Ubuntu, macOS, and Windows, plus an MSRV job on Rust 1.85. The release workflow runs the tests before it builds and publishes `SHA256SUMS` next to the binaries. Every release lists the SHA-256 hash of each binary there.
