# Crux v0.11.0

Crux v0.11.0 adds SCIP-backed architecture navigation for agents and people.

## Highlights

- `scip_architecture` reports module dependencies, package boundaries, cycles, and coverage.
- The MCP tool reads an existing index. It does not write files or run an indexer.
- Persistent Codex and Claude guidance routes architecture questions to the new MCP tool.
- `crux architecture .` creates `graph.html`, `GRAPH_REPORT.md`, and `graph.json`.
- The architecture CLI tries the required language indexer when the default index is missing.
- The normal language indexer prerequisites still apply.
- The MCP server caches each architecture projection and rebuilds it after the loaded index changes.

## Upgrade

```sh
crux self-update
crux setup codex
# Use `crux setup claude` for Claude Code.
```

Run setup again to refresh the persistent guidance.
Restart the client and any persistent MCP process after the upgrade.

## Coverage limits

Architecture results include only definitions and references in the SCIP index.
Runtime, generated, and reflective dependencies appear only when the indexer emits them.
Crux excludes malformed, unknown, and ambiguous references from graph edges.
The result reports these exclusions as coverage diagnostics.

The architecture evaluation verifies fixture correctness, query routing, and cached query behavior.
It does not measure model adoption or establish new token savings.
